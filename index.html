Mô tả quyền

player Tuyển thủ
Thi đấu, đăng nhập bằng mã giải + ID + MK, vào bàn được gán.
vip VIP
Như tuyển thủ, đánh dấu ưu tiên / khách mời.
mod Mod
Điều phối viên — hỗ trợ BTC (gán phòng, nhắc bàn).
caster Caster
Bình luận viên — xem / gắn phòng livestream.
admin Admin phụ
BTC phụ — hỗ trợ giải. Không tự mở panel website.
superadmin Admin chính
BTC chính — quyền cao nhất trên hệ thống giải. Chỉ session Admin website mới được gán/hạ role này.
🔒 Bảo mật: chỉ khi đã đăng nhập mật khẩu Admin website mới được gán/đổi admin và superadmin. Tài khoản superadmin không thể bị xóa khi còn là admin chính duy nhất.
